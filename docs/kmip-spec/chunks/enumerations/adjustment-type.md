# Adjustment Type

- **Spec versions**: `v2.0` `v2.1` `v3.0`
- **Introduced**: v2.0

| Name | Value | Versions |
|---|---|---|
| Negate | `Negate the value. Applies to Integer, Long Integers, Big Integer and Boolean types.` | `v2.0` `v2.1` `v3.0` |
| Decrement | `Subtract the Adjustment Parameter to the value. Applies to Integer, Long Integers, Big Integer, Interval, Date Time, and Date Time Extended. The default is parameter is 1 for numeric types, 1 second for Date Time, and 1 microsecond for Date Time Extended.` | `v2.0` `v2.1` `v3.0` |
